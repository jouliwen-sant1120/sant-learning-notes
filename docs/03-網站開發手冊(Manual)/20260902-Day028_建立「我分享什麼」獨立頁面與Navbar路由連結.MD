20260902-Day028_建立「我分享什麼」獨立頁面與Navbar路由連結

一、本期目標

將首頁 Navbar 的「我分享什麼」從原本的首頁區塊錨點，調整為真正的獨立頁面入口。

本期維持網站既有架構，不刪除首頁原本的「我分享什麼」框架區。

二、本期開發內容

1. 建立 Courses 獨立頁面

建立：

src/pages/Courses.jsx

頁面內容：

頁面標題：我分享什麼

說明工作、學習與實作經驗

說明內容範圍包含 AI、資料分析、工作效率與實務應用

2. 建立 Courses Route

在 App.jsx 中加入：

import Courses from "./pages/Courses";

以及：

<Route path="/courses" element={<Courses />} />

完成後可由：

/sant-learning-notes/courses

進入「我分享什麼」獨立頁面。

3. 修改 Navbar「我分享什麼」

原本：

<a href="#courses">我分享什麼</a>

調整為：

<Link to="/courses">我分享什麼</Link>

Navbar.jsx 原本已使用：

import { Link } from "react-router-dom";

因此不需新增 Router import。

三、首頁框架保留原設計

本期確認 Navbar 的「我分享什麼」與首頁的「我分享什麼」框架區，是兩個不同層級。

Navbar

我分享什麼
    ↓
/courses
    ↓
我分享什麼獨立頁面

首頁框架區

仍然保留：

我分享什麼
├─ AI 工作應用
├─ Power BI
└─ Excel

這些框框未來可各自作為內容入口，連結至對應的分類頁、文章或學習內容。

本期不刪除、不改變這些首頁框架。

四、測試結果

已確認：

http://localhost:5173/sant-learning-notes/courses

可以正常顯示「我分享什麼」頁面。

Navbar 的「我分享什麼」可以直接進入 /courses。

首頁原本的「我分享什麼」框架區仍然存在。
