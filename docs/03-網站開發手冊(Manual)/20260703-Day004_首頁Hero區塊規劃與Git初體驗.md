代表：

U

代表：

## 二、Git 工作節奏

Git 不需要修改一次就立即提交。

本專案採用：

完成一天工作

↓

撰寫工作日誌

↓

Git 建立版本

↓

GitHub 更新

讓 Git 紀錄與每日工作內容一致。

---

## 三、AI 協作方式

今日發現：

對初學者而言，

最大的困難並不是 Git。

而是：

不知道操作介面的位置。

因此建立新的協作原則：

當需要操作新功能時：

- 優先提供目前畫面截圖。
- AI 根據畫面逐步引導。
- 明確指出點擊位置。
- 一次只完成一個步驟。

避免因介面不熟悉而誤操作。
