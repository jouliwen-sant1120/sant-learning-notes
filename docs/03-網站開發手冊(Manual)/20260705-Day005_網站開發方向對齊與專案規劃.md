# 今日心得

今天最大的成果不是修改網站。

而是建立網站開發的方法。

網站並不是想到什麼就加入什麼。

而是：

每一個區塊都先完成需求對齊，再開始施工。

這樣才能降低重工，提高網站品質。

另外，也正式決定：

網站並非創造內容。

而是作為多年學習成果的展示平台。

因此，網站與各支線專案將同步成長，待網站主架構完成後，再逐步將成果展示於網站中。
