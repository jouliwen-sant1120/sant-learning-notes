# 1. 網站基本資訊

-   **網站名稱：** Sant 學習成長筆記（暫定）
-   **網站類型：** 混合型個人品牌網站
-   **一句話介紹：**
    陪伴每一位願意學習的人，把複雜知識變成容易理解、容易實踐的方法。
-   **品牌 Slogan：** 把複雜，變簡單。
-   **網站目的：**
    建立個人品牌、建立信任、分享知識、累積內容資產、為未來課程與服務做準備。
-   **目標受眾：** 願意持續學習，希望運用
    AI、資料分析與數位工具改善工作方式的職場工作者。
-   **希望訪客採取的行動：** 認識
    Sant、閱讀知識文章、持續追蹤網站、與我聯絡交流。

# 2. 網站使命與品牌定位

## 網站使命 (Mission)

運用自己的理解力、系統思考與持續學習精神，把複雜知識整理成人人都能理解並願意實踐的內容，陪伴更多人持續成長。

## 個人品牌定位 (Positioning)

陪伴學習者建立思考能力，將複雜知識轉化為容易理解、容易實踐的方法。

## 核心價值

-   持續學習
-   系統思考
-   真誠分享
-   知識轉譯
-   建立信任

## 品牌承諾

不只分享工具，而是分享能長期受用的思考方式。

## 品牌語氣

真誠、溫暖、清楚、專業、陪伴式。
